# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- Recruiters / hiring managers evaluating Catalin for software roles — must quickly grasp scope,
  quality, and stack range, then find a contact path.
- Clients / freelance leads weighing whether to commission work — need credibility, proof of
  delivery, and a way to reach out.

## Product Purpose

A personal developer portfolio that is the evidence-backed record of Catalin's work across web,
mobile, desktop, embedded, and AI/ML. Success means a visitor moves from browsing to a real
contact (application or inquiry) and takes away the breadth story.

## Positioning

Breadth is the point: one developer who ships across web, mobile, desktop, embedded, and AI/ML
with genuine depth — and proves it with real, evidence-backed projects rather than claims.

## Operating Context

- Actively used in job applications and client outreach, so first impressions and a fast contact
  path matter.
- Hosted on GitHub Pages (confirmed deploy target; domain/email in data/site.ts are placeholders).
- Visited on desktop and mobile; dark-first.

## Capabilities and Constraints

- One-page sections (hero, about, featured, explorer, stack, ML notebook, apps, journey, contact)
  plus project detail routes at /projects/[slug].
- Fully data-driven: all content lives in data/ (site, projects, skills, journey, ml).
- Dark / light / system theme, ⌘K command palette, screenshot galleries with lightbox.
- Strict no-fabrication rule: never invent metrics, stats, clients, or experience; leave fields
  out instead. Placeholder-flagged entries render a temporary treatment.
- English-only content.
- Featured projects: Vortex, Detectie, ATLAS, Siteauto, Jarvis.

## Brand Commitments

- Name: Catalin · Role: Software Developer · GitHub: github.com/Cata5.
- Voice: honest, evidence-first, no invented claims. "Currently building Vortex" narrative.

## Evidence on Hand

- PROJECT_ANALYSIS.md — every project claim verified against source, dated 2026-08-10.
- Real screenshots under public/projects/ (e.g. Vortex phone/TV, Primarie dashboard).
- GitHub remotes: github.com/Cata5 (Infuse/Vortex, AI-interface, Aplicatie-Teka, OmniStudio,
  Primarie, Agetic-OS-Helper).

## Product Principles

1. Evidence over claims — nothing fabricated, ever.
2. Breadth with honesty — show range, but flag partial/placeholder work.
3. Data-driven by design — content stays in data/ so the site remains trivially maintainable.
4. Real work beats logos — projects, screenshots, and code over tool lists.
5. Fast to judgment — a visitor must grasp scope and contact path within one glance.

## Accessibility & Inclusion

Dark/light/system themes and a keyboard-driven command palette; no other product-specific
requirement has been established.
